Redes e Internet

Una red conecta dispositivos para compartir información y comunicarse entre sí.

Información: A continuación se muestran algunos conceptos básicos relacionados con las redes informáticas.

Internet

La red mundial que permite visitar páginas web y utilizar servicios online.

Red pública

Red Local

Conecta dispositivos dentro de una vivienda, centro educativo u oficina.

LAN

Nube

Permite guardar archivos en Internet para acceder a ellos desde cualquier lugar.

Cloud

Router

Gestiona la conexión entre la red local y el acceso a Internet.

Hardware

Seguridad

Las contraseñas seguras y las actualizaciones ayudan a proteger la red.

Wi‑Fi

Dispositivos

Ordenadores, móviles y tablets pueden conectarse por cable o Wi‑Fi.

Conexiones

Recomendaciones

  • Cambiar la contraseña predeterminada del router.
  • Utilizar WPA2 o WPA3 en la red Wi‑Fi.
  • Evitar introducir datos importantes en redes públicas.
  • Mantener actualizados los dispositivos conectados.
